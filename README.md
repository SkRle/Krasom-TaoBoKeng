# ระบบหลังบ้าน ศาลเจ้ากระโสมเต้าโบ้เก้ง

ระบบจัดการข้อมูลม้าทรง พี่เลี้ยง คณะกรรมการ และตำแหน่ง ของศาลเจ้ากระโสมเต้าโบ้เก้ง

```bash
nvm use
npm install
cp .env.example .env   # แล้วกรอกค่าตาม CLAUDE.md > Environment setup
npm run dev
```

รายละเอียดโครงสร้างโปรเจกต์ เทคโนโลยี และแนวทางการพัฒนา ดูที่ [CLAUDE.md](CLAUDE.md)
